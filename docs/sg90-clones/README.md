# SG90 clone database

"SG90" is a shape, not a spec. Every brand - clones and genuine TowerPro
alike - ships its own internals behind the same case. Mechanically the
cases, pots, and layouts are near-identical across brands; what actually
differs, and what matters for drive electronics and reliability, is the
**gear train** and the **motor**. This folder records exactly those two
things per brand, one file per servo model, so brands can be compared
before committing a fleet to one.

Each entry records:

- Gear train: tooth counts per stage, overall ratio, modules, materials,
  and any observed failure pattern (which gear strips, under what load).
- Motor: can dimensions and family, shaft/boss geometry, terminal
  arrangement, rotor construction, and electrical characteristics as
  they get measured.
